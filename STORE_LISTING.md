# Chrome Web Store Listing Draft

## Name

GPT List Mask

## Short Description

Mask chatbot conversation titles by default and reveal them only when needed.

## Detailed Description

GPT List Mask protects privacy in chatbot sidebars by hiding non-current conversation titles. The current conversation remains visible. Other titles are masked with a soft skeleton bar by default, reveal while hovered or keyboard-focused, and can be permanently unlocked per title with a triple-click.

Supported known sites include ChatGPT, Claude, Qwen, Z.ai, Xiaomi XiaoAI/MiMo, MiniMax/Hailuo, DeepSeek, Kimi, Doubao, Tencent Yuanbao, ChatGLM, Tongyi, ERNIE/Yiyan, Gemini, Copilot, Perplexity, Poe, Mistral, and Grok. Other chatbot sites can be enabled from the popup with a single-site optional permission request.

Privacy commitments:

- No network calls.
- No telemetry.
- No remote code.
- No title uploads.
- Raw titles are not stored.

## Permission Summary

GPT List Mask uses storage for local settings, activeTab and scripting to refresh the current page after popup changes, and narrow static host permissions for supported chatbot domains. Optional host access is requested only for a user-enabled custom site.
